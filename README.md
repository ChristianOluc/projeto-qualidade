# Projeto Qualidade

Projeto desenvolvido em Python com foco em testes automatizados,
integração contínua e pipeline de qualidade.

## Tecnologias

- Python 3.13
- Pytest
- Git
- GitHub
- GitHub Actions

## Funcionalidades

O projeto possui uma calculadora com as operações:

- Soma
- Subtração
- Multiplicação
- Divisão

A divisão por zero também possui tratamento de exceção.

## Testes

Os testes automatizados são executados utilizando Pytest.

Para executar:

```bash
pytest
